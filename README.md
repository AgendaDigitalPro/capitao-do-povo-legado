# Red Star Quiz

Quero fazer um quiz gamificado IDENTICO aos prints que eu vou te mandar 
ATENÇÃO: Unica coisa que mudará e que o quiz será de extrema esquerda com as cores branco e vermelho, estrelas vermelhas, palavras gatilhos deles. Cada etapa do quiz eu vou te mandando então quando for passar para a etapa 2 eu te falo e assim por diante, vamos agora começar com a etapa 1.
